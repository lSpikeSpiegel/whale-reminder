## 1. 手势总览

| 操作 | 行为 | 说明 |
|---|---|---|
| 单击**头部** | 摸头 | 腮红 + 爱心粒子 + 台词，1.5s 后回神 |
| 单击**身体** | 戳一戳 | 左右晃两下 + 台词，1.2s 后回神 |
| **2.5 秒内连戳 5 下** | 生气 | 脸黑 + 抖动 + 台词，之后 12 秒冷战，摸头会被顶回来 |
| **6 秒内连摸 3 下** | 得意 | 屑屑眼 + 台词，3.2s 后回神 |
| 双击 | 打开待办面板 | 单击动作已经执行过，不影响 |
| 左键拖拽 | 移动 | 跟手倾斜（±8°），松手落地回弹 |
| **快速甩出后松手** | 甩出去 | 按松手速度滑行，撞到工作区边缘反弹，停稳后可能委屈 |
| 拖到屏幕边缘松手 | 贴边停靠 | 26px 内自动吸附到工作区边缘；**甩出去时不吸附**，免得两套逻辑抢坐标 |
| 右键 | 原生菜单 | 摸头 / 戳一戳 / 动作 / 贴边 / 移到下一块显示器 / 叫回来 / 打开面板 / 隐藏 |
| 拖入文件 | 吃点心 | 只播进食动作，**不删除文件**（见第 6 节） |
| 鼠标移入 | 抬头 | 仅在常态 / 贴边待机时触发，不打扰睡觉 |

单击动作**立刻执行**，不等双击判定窗口。摸头这种互动必须跟手，等 280ms 就变成了「点不动」。

## 2. 待机状态机

两把尺子分开量：

- **away**（系统闲置，`GetLastInputInfo`）——决定**睡不睡**。人在写代码时她该安静待着，
  不该自顾自地睡过去；人真离开了，几分钟就该睡着。
- **sincePet**（多久没点我）——决定**颓不颓**。用户一直在用电脑但从不理她，她照样越来越丧。

| 条件 | 档位 | 动作池 |
|---|---|---|
| away ≥ 8min（夜间 ×0.45） | asleep | `sleep`（盖被子） |
| away ≥ 4min | dozy | `doze`（站着点头打瞌睡） |
| sincePet ≥ 90s | lazy | `slack` / `bored` / `daydream` |
| sincePet ≥ 20s | dreamy | `daydream` / `think` / `idle` |
| 其它 | calm | `idle`（贴边时换成 `peek`） |

规则：

- `away` 一定不大于 `sincePet`（点桌宠本身也算系统输入），所以两段判断不会打架。
- 系统闲置每 2 秒轮询一次；拿不到（纯浏览器里跑）就退回只按 `sincePet` 算。
- 每个动作有 6–34s 的随机停留时长，演完才重新抽签；抽签有一半概率留在当前动作，避免每十秒换一次脸。
- 夜间 23:00–07:00 阈值打到 **0.45 折**，熬夜时她先困。
- 任何点击、拖拽都会把空闲计时归零；从 `doze` / `sleep` 被叫醒时先演一段 `happy` 再说「呼噜……唔，醒啦！」。
- **离开之后再回来**（away 从 ≥4min 掉到 <3s）：如果她正睡着，主动演 `happy` 说「唔…你回来啦」。
- 提醒触发 → 强制 `work` 6 秒，结束后交还状态机。
- 右键菜单 / 托盘选的动作是「钉住」的，演 5.2 秒后交还状态机。

实现：`src/pet/usePetBehavior.ts`，900ms 心跳 + 2s 闲置轮询。

## 3. 动作清单

18 个动作。写实版用 8 张表情立绘（默认 / 脸红 / 爱心眼 / 圈圈眼 / ><眼 / 屑屑眼 / 脸黑 / 流泪），
Q 版（归档）仍用 11 张，靠 CSS 动效和粒子区分。

| 动作 | Q 版立绘 | 写实立绘 | 动效 | 粒子 |
|---|---|---|---|---|
| `idle` | front | front | 呼吸 4s | — |
| `react` | front | front | 上浮 4px | — |
| `pat` | front | blush | 下沉回弹（squash & stretch） | 爱心 ×5 |
| `poke` | front | squint | 左右晃 2 次 | — |
| `happy` | playing | heart | 蹦 2 下 | 爱心 + 星星 |
| `think` | thinking | squint | 慢摇 6.4s | — |
| `slack` | slacking | front | 更慢更懒的摇 9s | — |
| `daydream` | daydreaming | front | 呼吸放缓到 7s | — |
| `bored` | bored | dizzy | 整体下沉 2–3px | — |
| `doze` | front | front | 点头 3.4s | zzz |
| `sleep` | sleep | front | 慢呼吸 8s | zzz（更慢更大） |
| `work` | working | front | 高频微抖（笔尖） | — |
| `eat` | eating | heart | 一口一口 460ms | 爱心 |
| `drag` | side | front | 跟手倾斜，无呼吸 | — |
| `peek` | side | front | 侧身靠墙，无呼吸 | — |
| `angry` | bored（借用） | **gloom** | 抖动 320ms ×2 | — |
| `smug` | playing（借用） | **smug** | 得意地晃两下 | 爱心 ×3 |
| `sad` | bored（借用） | **tears** | 下沉 + 轻微摇晃 | — |

Q 版那三行标「借用」的，是因为它已经归档、不再补新素材，只能拿最接近的姿势顶一下。

眼睛与腮红坐标全部从 `assets/pet/meta.json` 的 `eyes` 推出来，没有额外标定。
写实素材没有眼睛标注，所以不吃 CSS 腮红（PSD 里的脸红是真画上去的）。

### 为什么不做闭眼 / 眨眼

位图立绘没法真的把眼睛闭上。曾经试过在眼睛位置压一条深蓝色短横来伪装闭眼，
但立绘本身是睁眼高光的，盖上去之后读起来不是「闭着眼享受」，而是**在脸上贴了两条黑杠**——
眨眼那 110ms 尤其明显。试过用肤色椭圆盖住眼睛再画睫毛弧线，效果更差：
椭圆会把眼周的高光和睫毛一起抹平，脸像贴了块膏药。

结论是**不装**：宁可眼睛一直睁着，也不要假。`pat` / `doze` 靠下沉回弹、点头、腮红、爱心和 zzz
表现情绪，比画一条线可信。真要闭眼，得补一张 `front-closed.webp` 走整图交叉淡入。

## 4. 贴边停靠

### 4.1 吸附

松手时取窗口到**工作区**（已排除任务栏）四条边的距离，最近的一条 ≤ 26px 就吸上去。
工作区来自 `Monitor::work_area()`，任务栏在左边、上面、自动隐藏都不用特殊处理。

状态存进 `window.json` 的 `dock` 字段（`left` / `right` / `top` / `bottom`），
重启后先按上次坐标定位，再按 `dock` 重新吸附一次——换分辨率也不会飘。

### 4.2 表现

- 立绘切成 `side`，**朝屏幕内侧**：贴左边时镜像（`scaleX(-1)`），贴右边时用原图。
- 停止呼吸浮动（`pet--docked` 关掉 `pet-breathe`），否则靠墙站还上下浮会穿模。
  只有 `doze` / `sleep` 保留慢动作。
- 常态从 `idle` 换成 `peek`：侧身靠着，像在墙边歇脚。

### 4.3 探头

贴着左右边、并且已经**睡熟**（`sleep`，不是打瞌睡）20 秒后，窗口向屏幕外挪 42% 宽度，只露一半。
鼠标移进剩下那半边，立刻滑回原位。

只认 `sleep`：`doze` 状态下她会反复抬头，探头收头会抖个不停。

- 探头期间的位置**不落盘**（`pet::is_docked` 为真时位置保存器直接跳过），
  否则「家」坐标会被半个身子在屏幕外的坐标覆盖。
- 取消贴边时先滑回原位再存坐标。

## 5. 台词气泡

复用提醒用的 `bubble` 窗口，靠尺寸区分：

| 类型 | 尺寸（逻辑 px） | 内容 | 存活 |
|---|---|---|---|
| 提醒卡（追问） | 280 × 132 | 标题 + 剩余时间 + 一行回答按钮 | 15s |
| 提醒卡（截止） | 280 × 156 | 标题 + 剩余时间 + 主操作 + 快捷时刻 | 15s |
| 提醒卡（开始） | 280 × 196 | 标题 + 剩余时间 + 三行按钮 | 15s |
| 提醒卡（选时间） | 280 × 250 | 上面那行换成近 7 天横条 + 时分步进器 + 取消 / 确定 | 60s |
| 台词 | 236 × 88 | 一句话胶囊，无按钮 | 3.2s |

尺寸在 `scheduler.rs`（`ASK_SIZE` / `DUE_SIZE` / `START_SIZE`）和 `Bubble.tsx`
（`ASK_HEIGHT` / `DUE_HEIGHT` / `START_HEIGHT`）各有一份，改一处要同步另一处。

### 5.1 按钮按 phase 分

调度器在 `reminder://fire` 的 payload 里带一个 `phase`，气泡据此换按钮：

| phase | 判定 | 按钮 |
|---|---|---|
| `ask` | `kind = ask` | 已完成 / 进行中 / 还没开始 |
| `start` | `rule` 里有 `"origin":"start"` | **已开始** ／ 1 小时后 · 今早 9 点 · 明早 9 点 ／ 15 分钟后 · 晚点提醒我 |
| `due` | 其余一次性提醒、循环提醒 | **已完成** · 15 分钟后 ／ 1 小时后 · 今晚 5 点 · 明晚 5 点 |

快捷时刻（胶囊行）按 phase 分两套，都是「以此刻为基准」算的，**气泡和面板共用同一份**
（`ui/date.ts` 的 `quickTimes`，别在两边各写一套）：

- `start` → 早上：1 小时后 / 今早 9 点 / 明早 9 点
- `due` → 傍晚：1 小时后 / 今晚 5 点 / 明晚 5 点

已经过去的整点**直接不显示**（`clockAt` 返回 null）——后端 `reschedule_reminder` 和建任务
都会拒绝过去的时间，点了只会看到一行报错，不如别给。所以上午 11 点看开始提醒，
快捷行只有「1 小时后 / 明早 9 点」两颗。

面板里这两行胶囊挂在对应开关下面（`.option--sub`），开关关掉就一起收起；点胶囊会顺手把
开关打开并把时刻写进右边的 DatePicker，用户还能再手动微调。

开始提醒和结束提醒在库里都是 `kind = notify` 的一次性提醒，只能靠建它时写进 `rule` 的
`origin` 标记区分（`reminder::ORIGIN_START`）。改之前两者共用「已完成」，开始时间到了却
提示「已完成」很别扭。

「已开始」= `update_task(status: doing)`，`started_at` 由后端补。
「15 分钟后」「晚点提醒我」和快捷时刻都走 `reschedule_reminder(reminder_id, at)`——**按提醒挪，不按任务挪**：
一次性提醒响完 `state` 就是 `done`，旧的 `snooze_task` 只改 `pending` 的，点了等于没点。

- 提醒优先：`BUBBLE_KIND` 记录当前内容，提醒显示期间台词直接丢弃，不会把提醒顶掉。
- 位置由 Rust 统一计算（`place_above`），台词只压住头顶 10px，提醒压 24px。
- 兜底隐藏靠 `BUBBLE_GEN` 代数，旧定时器不会关掉新气泡。

台词只在**有互动**时出现（摸头、戳、拖完、贴边、投喂、被叫醒），
待机摸鱼 / 发呆有 25% 概率嘀咕一句，不会话痨。

## 6. 文件投喂（有意做了减法）

参考项目把拖进来的文件**移到回收站**并恢复饱腹值。本实现只播进食动作，**不动文件**。

原因：

1. 桌宠的核心职责是待办提醒，不是文件清理器；
2. 拖错一个文件夹就是不可逆操作，确认成本比彩蛋价值高；
3. 不引入 `trash` crate，少一个依赖、少一处平台差异。

如果以后要做真投喂，正确做法是：落点必须命中不透明像素 → 弹一次确认（列出文件名）→ 走系统回收站 → 失败项原样保留。

## 8. 已知取舍

| 问题 | 处理 |
|---|---|
| 窗口是包围盒（176² 或 172×340），四角透明区域仍会挡鼠标 | 沿用原方案的既定代价；气泡窗口会动态缩到内容尺寸，减少遮挡 |
| 位图无法做骨骼动画 | 靠 18 套 CSS 动效 + 粒子 + 台词补表现力 |
| 拖拽时 `startDragging` 会让指针事件丢失 | 用窗口 `Moved` 事件的「停手 420ms」兜底收尾，指针抬起和兜底谁先到算谁 |
| 探头期间窗口有一半在屏幕外 | 只露 58%，可见部分足够 hover 回来；上下贴边不做探头 |
| 右键菜单是原生菜单，样式不可定制 | 和托盘菜单保持一致的观感，换来零渲染成本 |
| **甩出去和贴边会抢同一个坐标** | 甩出去时先 `undock` 清状态、不吸附；落地停稳后才重新 `snap` 一次 |
| **眼睛不会跟随光标**（参考项目有） | 静态立绘没有可转动的眼球；要做到得接 Live2D 参数 `ParamEyeBallX/Y` |
| **不会随音乐跳舞 / 站到窗口顶边** | 需要音频回环捕获、窗口枚举与跟随，属于另一个量级的功能，本期不做 |
